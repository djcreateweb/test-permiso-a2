# Test Permiso A2

Teoría completa por capítulos y web de práctica del examen teórico específico de moto (permisos A1/A2) de la DGT, con 200 preguntas tipo test, imagen, corrección en verde y rojo, explicación de cada respuesta y apartado de preguntas falladas.

Web (teoría por capítulos y test): https://djcreateweb.github.io/test-permiso-a2/teoria/

Las preguntas son de elaboración propia basadas en el temario de la DGT (normativa vigente a octubre de 2026). Las señales proceden del catálogo oficial español y las etiquetas ambientales del repositorio MarcEsteve/distintivo-ambiental-dgt.
